## Learning experiment

### My idea (hypothesis)

I think I work better when I do a **25-minute focus block** with:

- phone in another room  
- notifications off  
- only 1–2 browser tabs open  

…compared to working with my phone next to me, notifications on, and lots of random tabs open.

If that’s true, I should finish a small task **faster** and get **distracted less**.

### Why I tested this

In earlier weeks I kept jumping between Slack, GitHub, docs, and my phone. It felt busy, but I didn’t always get much done. I wanted to check if a simple Pomodoro-style focus block actually helps me for this subject.

### How I tested it

I used myself as the test (same laptop, same kind of task).

**Condition A — Distracted**
- Phone on the desk  
- Notifications on  
- 5+ unrelated tabs open  

**Condition B — Focused**
- Phone away  
- Notifications off  
- Max 2 tabs for the task  
- 25-minute timer  

**Task:** a small CP3402 job (for example fixing/adding something in my Prac 7 PHP site, or writing a short journal/README section). Same type of task for both conditions.

**What I measured:**
1. How many minutes until I finished  
2. How many times I got interrupted (phone checks, random tabs)  
3. How focused I felt (1 = bad, 5 = really focused)

**Steps:**
1. Write down the task first  
2. Do Condition A and record the numbers  
3. Take a 10-minute break  
4. Do Condition B on a similar-sized task  
5. Compare the results  

**How I decide if my idea worked:**  
Focused mode should be **faster** and have **fewer interruptions**. If only one of those improves, it’s mixed. If focused mode is worse, my idea was wrong.


### What this means for me

- If it worked: I’ll keep using 25-minute focus blocks for the rest of the pracs and group work.  
- If it didn’t: I’ll try something else (longer blocks, or a different way to cut distractions).
