# Week 1 — Vegely

## Project Overview for Week-1

This week, I designed and created **Vegely**, a simple multi-page website for a healthy food delivery startup based in Singapore. The website includes four pages: **Home**, **Menu**, **About**, and **Cart**. I built the website using **HTML5, CSS3, Bootstrap 5, and JavaScript** without using any CMS or website builder. The project is uploaded to GitHub and deployed online using Vercel at [vegelyweb.vercel.app](https://vegelyweb.vercel.app).

## Restaurant Project Goal

### Goal

- Our restaurant aims to promote healthy eating by delivering fresh, nutritious, and affordable meals to busy students and working adults in Singapore through a modern food delivery platform.

### Explaining the website goal

- The goal of the website is to introduce healthy restaurant startup, show its food and services, build customer trust, and encourage people to order healthy meals online.
